# Linear Search vs Binary Search

| Feature | Linear Search | Binary Search |
|---|---|---|
| Data requirement | Can work on unsorted data | Requires sorted data |
| Searching method | Checks elements one by one | Divides the search range into two halves |
| Best-case time | O(1) | O(1) |
| Average-case time | O(n) | O(log n) |
| Worst-case time | O(n) | O(log n) |
| Space complexity | O(1) | O(1) |
| Suitable for | Small or unsorted datasets | Sorted and larger datasets |

## Conclusion

For this organisational hierarchy, the department names are stored in sorted order. Therefore, Binary Search is more suitable for repeated department searching because it requires fewer comparisons as the dataset grows.
